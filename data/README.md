# StudentMan data

此目錄保存目前學校邀請名單研究的可追蹤資料快照。

## 現行來源檔

本輪使用者提供的主 Excel：

`台灣設計_汽車_引擎_機械電機航太_NVH_全台學校邀請名單_格式統一版_20260930.xlsx`

目前 Excel 維持三個工作表：

1. `總訊息`
2. `大學科技大學技術學院等`
3. `高中職`

大專與高中職的 A–V 欄已統一為：

`學校｜科系／科別｜類別／群別｜學制／部別｜114相關學生數｜校長｜校長電話｜校長分機｜校長Email｜主任／主要窗口｜窗口電話｜窗口分機｜窗口Email｜單位辦公室電話｜單位辦公室分機｜單位辦公室Email｜學校總機｜地址｜學校官網｜聯絡資料來源｜人數來源｜查核狀態`

W 欄之後才放各學制專屬補充欄位。

## 目前人數缺口

- 大專原始空白：81 筆
- 其中非獨立招生研究中心／實驗室：7 筆，學生數 N/A
- 真正待補正式系所／學程：74 筆，約 38 所大專校院
- 高中職待補相關科別實際在學人數：172 校

## 大專最終統計規則

以「同一邀請／行政窗口」為統計單位。同一系所／系辦／主任窗口下：

- 學士
- 進修
- 碩士
- 碩專
- 博士
- 國際專班
- 技優專班
- 產學專班
- 雙軌或其他由同一窗口承接的班別

全部合併。

不同窗口才分列。

## 高中職統計規則

以學校為主要邀請單位，把本案相關科別的 114 學年度實際在學人數加總。

## 檔案

- `student-count-findings-2026-09-30.csv`：目前已找到的 18 組大專人數資料，以及新合併規則下的最低已知合計。
- `../research/student-count-research-2026-09-30.md`：研究規則、缺口、資料來源與後續流程。

## 注意

CSV 裡的「新規則最低合計」不是全部都已 final。若狀態寫「待查其他同窗口專班」，代表仍需繼續從 114 學年度官方資料找齊後才能作為最終人數。

主 Excel 暫不因尚未完成的人數研究而回寫；等全體大專與高中職人數核實完成後，再一次更新。
